# ⚔️ LifeQuest AI

Gamified AI productivity app that turns your daily tasks into RPG-style quests.

---

## 🚀 Features

- 🎯 AI-generated quests
- 📈 XP & leveling system
- 🔥 Daily streak tracking
- 🏆 Achievements system
- 🧙 Avatar selection
- 📜 Quest history (game log)

---

## 🛠️ Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- Ollama AI

---

## ▶️ Run Locally

```bash
npm install
npm run dev
